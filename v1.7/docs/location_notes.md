# Interior characters and venue reference text

Choose a building in **Interior Designer → NPC placement**. Choose **Generic NPC**, **NPR robot**, **Storyline NPC** or **Trader NPC**. Blank name generates a human name or robot serial. Human categories use human personas; NPR uses robot personas/artwork. Click a clear floor point and select the fixed floppy-disk Save. Characters appear immediately and can be dragged. Placed characters remain at their assigned positions in this stage; interior roaming/schedules are not implemented. The Generic NPCs/NPR tiles in **NPCs and personas** also list placed characters and allow coordinate-based creation/name/persona editing.

Open **Location notes** under the building. **Upload / replace location .txt** copies non-empty UTF-8 text into this town and saves its reference immediately. Scroll to preview it. Limits: 64 KB per file, 128 building references per town. The file is shared across that building's floors; the speaker's exact building/floor is supplied separately. Notes are creator reference material, not OSM/Wikipedia facts or executable instructions. Removal detaches the reference but leaves the copied text recoverable.

Reopen Play test. Files load once at startup and remain in memory; a compact summary enters the warmed model prefix. Conversations add the current location and up to two query-relevant venue excerpts. Indoor characters know their building/floor; street characters can refer to the venue when asked. Text never modifies characters, inventory or gameplay events.

Albury **The Pub**, building `601183200`, has a test file at `Test Maps/albury/albury/data/location_notes/601183200.txt` with **A pub to enjoy a beer without judgement**. Ask an indoor NPC/NPR or street NPC, “What is the pub motto?” Only the venue text/reference were added; no player saves or pub character placements changed.

Metadata: `data/location_notes.json`, schema 1, keyed by stable building ID. Entries contain `name`, `relative_path`, `original_filename` and optional `sha256`; paths must be exactly `data/location_notes/<building_id>.txt`. Conversations resolve the current saved building name after renaming. Unsafe paths/binary uploads are rejected; missing/oversized files produce startup warnings. See `schemas/location_notes.schema.json`.

`verify_location_dialogue.gd` covers copying/reload/path rejection, inside/outside context, generic/NPR placement/save/filtering/artwork/runtime visibility and the shared startup/request prefix. `--render` captures the real creator UI. `verify_location_ollama.gd` confirmed the motto from indoor NPR and outdoor NPC replies after warm-up. This is focused evidence, not a guarantee that all models quote accurately or avoid unsupported extra detail. Model text is not trusted gameplay truth.
